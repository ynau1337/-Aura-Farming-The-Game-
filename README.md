# Aura Farming: The Game

2D-игра в жанре arena-survival, разработанная на языке Python с использованием библиотеки `pygame`.

## Особенности текущей версии
- **Управление персонажем:** плавное перемещение в 8 направлениях с нормализацией диагональной скорости.
- **Анимации:** динамическое переключение между анимациями покоя (`rest`) и бега (`run`).
- **Модульная архитектура:** логика персонажа, врагов, оружия и интерфейса разделена на независимые модули.

## Структура проекта

```text
aura-farming-the-game/
├── main.py                 # Точка входа, главный игровой цикл и рендеринг
├── player.py               # Класс игрока, физика движения и обработка анимаций
├── enemy.py                # Логика противников и система спавна
├── weapon.py               # Система вооружения и атак
├── ui.py                   # Пользовательский интерфейс и HUD
├── README.md               # Документация проекта
└── assets/                 # Игровые ресурсы (графика, звуки, шрифты)
    └── player/
    └── enemy/
    └── sprites/
    └── sound/
    └── font/
```

## Установка и запуск

1. **Убедитесь, что у вас установлен Python** (рекомендуется версия 3.10 или выше).
2. **Установите библиотеку `pygame`:**
   ```bash
   pip install pygame
   ```
3. **Запустите игру** из корневой директории проекта:
   ```bash
   python main.py
   ```

## Управление

| Действие | Клавиши |
| :--- | :--- |
| Движение вверх | `W` или `↑` |
| Движение вниз | `S` или `↓` |
| Движение влево | `A` или `←` |
| Движение вправо | `D` или `→` |
